# TradeTracker

Modern trading journal dashboard built with Next.js, Tailwind CSS, shadcn/ui, Lucide icons, and Recharts.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Features

- Dark slate finance theme with emerald profit / rose loss styling
- Sidebar navigation with mobile sheet drawer
- KPI metric cards, equity area chart, asset donut chart
- Trade log with local persistence (no auto-seeded demo trades)
